## Langkah 1: Setup Project (Vite)

### Buka VSCODE, open new folder (buat folder baru)

Buat folder project kosong untuk menyimpan code base nanti. dan buka visual studio code di dalam folder tersebut.

- Buka VSCODE
- Menu File -> Open Folder

### Install Project React

Buka terminal/CMD di dalam vscode, lalu jalankan perintah berikut untuk menginisialisasi project React menggunakan Vite:

```bash
# 1. Membuat project baru
npm create vite@latest frontend-series -- --template react

# 2. Masuk ke folder project
cd frontend-series

# 3. Tes project
npm run dev
```
